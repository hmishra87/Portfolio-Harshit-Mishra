# Portfolio-Harshit-Mishra

> **Harshit Mishra** — DevOps Engineer & Cloud Infrastructure Specialist  
> Interactive 3D Portfolio built with React 19, Vite, Three.js, and Tailwind CSS.

---

## 🚀 Features

- **Interactive 3D Architecture Core**: Real-time Three.js cloud topology with mouse parallax and drag-to-orbit controls.
- **Profile 3D Morph**: Seamless cursor hover transition between executive portrait and the 3D infrastructure engine.
- **3D Career Progression Line**: Chronological transit track (*Katyayan Group* ➔ *HyperTechGlobal* ➔ *Match Best Software*) with a 4-second auto-cycle and raycasted clickable 3D station dots.
- **Production AI Case Studies**: Interactive 3D architecture topologies for **Xelta.ai**, **Streamplay.ai**, and **Healnova.ai**.
- **Verified Credentials**: AWS Certified Solutions Architect (SAA-C03), Microsoft Certified Azure Administrator (AZ-104), and Jetking Diploma in Network Administration.
- **DevSecOps Gating**: Automated CI/CD release pipelines, SonarQube code quality gates, Trivy container security scans, and 99.9% production SRE uptime SLA.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **3D Graphics & WebGL**: Three.js
- **Icons**: Lucide React
- **Typography**: Plus Jakarta Sans, Outfit, JetBrains Mono
